About this Laboratory

This is a theoretical Black-Scholes-Merton analytical laboratory for European options with continuous dividend yield — not a market pricing engine.

Assumptions: European exercise · continuous dividend yield q · continuous compounding · constant volatility · constant risk-free rate · no transaction costs · no bid/ask · no early exercise · no volatility smile · no stochastic rates/vol.

All inputs are user supplied / theoretical. No fake live market data is used.

Model

$$d_1=\frac{\ln(S/K)+(r-q+\sigma^2/2)T}{\sigma\sqrt{T}},\quad d_2=d_1-\sigma\sqrt{T}$$

$$C=Se^{-qT}N(d_1)-Ke^{-rT}N(d_2),\quad P=Ke^{-rT}N(-d_2)-Se^{-qT}N(-d_1)$$

Conventions

Vega: raw ∂V/∂σ (per unit σ=1.00). Display toggle also shows per vol point (÷100).

Theta: analytical calendar theta ∂V/∂t = −∂V/∂T (annual). Daily = annual/365 (or /252 for ACT/252 display).

Charm / Color: calendar-time convention ∂/∂t = −∂/∂T (time-to-expiry).

Moneyness: primary metric ln(F/K) with F=Se^{(r−q)T}. For puts, ITM/OTM uses −ln(F/K).
